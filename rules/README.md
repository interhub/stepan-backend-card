# Code Rules

The code style of this project, adapted to NestJS, GraphQL and Prisma.

They apply to all code in this repository: `src/**` and `api/**`.

- `ts-code-style.md` - general TypeScript style, naming, size limits, anti-patterns.
- `project-structure.md` - where a new file goes and what to check for reuse before writing one.
- `services-and-data-access.md` - layer contracts, Prisma queries, asynchronous code, logging.
